# Translation source

All authored interface/guide copy is indexed here. `en.json` is the English source catalog; `tr/de/es/fr/hu/it/ja/ko/pt/ru/zh.json` contain translations, `patterns.ts` the Turkish dynamic rules and `references.json` the source-file inventory. The twelve language options are defined in `languages.ts`. Festival and achievement translations live here. Labels taken from the user's game remain local and take precedence in the selected language. New-language coverage includes menus/new-feature controls; untranslated long guides explicitly fall back to English.

Existing English phrases are stable lookup keys. Change the right-hand value in `en.json` or `tr.json`, not the key, to edit copy without changing saved IDs or option values. English overrides are generated into `runtime-en.json` before development, tests and production builds; this generated file avoids bundling thousands of duplicate identity strings. Do not edit it by hand.

Run `npm run locale:collect` after adding UI/guide/native-error copy, and `npm run locale:check` to validate catalogs. Missing Turkish entries deliberately fall back to English; the report lists this count. Some inventory keys are reference names or native error templates, so the count is not a count of visibly untranslated screens. Dynamic text rules live in `patterns.ts`; preserve captured player names, item IDs, numbers and coordinates. To add a language, add a catalog, register it in `catalog.ts`/the locale selector and provide its dynamic rules.

User-authored farm/player names and personal tasks are excluded from translation. In 0.10 the live connection uses the game's language and current native item names; the legacy offline recipe fallback uses ASCII English for font compatibility. `scripts/build-bridge-text.mjs` generates `bridge-goals.json` from authored templates and canonical public labels for embedding into the original bridge DLL. No extracted game text belongs there. `authoring/seed-core.mjs` and `seed-expansion.mjs` retain original translation authoring tables; catalog JSON is the runtime source. Extracted game text, private saves, proprietary art and game scripts must never be committed. Game terminology takes precedence over editorial wording when a local translation exists.
