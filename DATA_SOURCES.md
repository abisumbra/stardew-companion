# Sources and verification

Research dates: **2026-10-15–19**. Network access is used by explicit development/import operations and optional Steam buttons, never normal application startup.

### 0.10 connection, farm and Steam research — 2026-10-19

The official [Steam global achievement listing](https://steamcommunity.com/stats/413150/achievements/?l=english) returned 49 achievements in its server-rendered catalog. `data/steam-icons.json` retains exact API names and official achieved/locked icon URLs, without pixels. The native downloader successfully cached all 49 official JPEGs. Public profile XML under `/stats/413150/?xml=1&l=english` was inspected; incomplete/private data is refused.

[Farm Maps](https://wiki.stardewvalley.net/Farm_Maps) supports eight original layouts. Original maps, recipes, dimensions and selected-language item names are read from the installed game. [Modding:Translations](https://wiki.stardewvalley.net/Modding:Translations) and installed language assets establish the twelve official language codes. Authored guide translations remain partial.

The connection follows Microsoft's documented [.NET startup hooks](https://learn.microsoft.com/en-us/dotnet/core/tools/dotnet-environment-variables#dotnet_startup_hooks) and uses [Harmony 2.4.3](https://github.com/pardeike/Harmony) under MIT. Read-only local inspection and isolated native-type tests checked vanilla 1.6.15 action dictionaries, quest fields and placement methods. No game assemblies, extracted text, code or private saves are distributed. Full game-window behavior remains a validation limit.

## Knowledge policy

### Local artwork, maps and game identities (0.3.0)

The installed game's `Content/Data` dictionaries supply item names/descriptions, texture paths, sprite indices, recipe outputs, ingredient quantities, explicit personal gift IDs and world-map rectangles at runtime. They do not override the versioned Perfection rules or verified planner guides. Textures are read from the user's installation, decoded in memory and never bundled. Data schemas were checked against the public serialization metadata of the local 1.6.15 assembly; the application does not load or execute that assembly.

Format references checked through the research service on 2026-10-15:

- [Wiki item namespaces](https://stardewvalleywiki.com/Modding:Items), [objects](https://stardewvalleywiki.com/Modding:Objects), [tools, revision 190707](https://stardewvalleywiki.com/mediawiki/index.php?title=Modding:Tools&oldid=190707), [trinkets, revision 190719](https://stardewvalleywiki.com/mediawiki/index.php?title=Modding:Trinkets&oldid=190719).
- [Furniture fields, revision 190703](https://stardewvalleywiki.com/mediawiki/index.php?title=Modding:Furniture&oldid=190703), [hat fields/layout, revision 183081](https://stardewvalleywiki.com/mediawiki/index.php?title=Modding:Hats&oldid=183081), [boots](https://stardewvalleywiki.com/Modding:Boots), [shirts](https://stardewvalleywiki.com/Modding:Shirts), [pants, revision 190705](https://stardewvalleywiki.com/mediawiki/index.php?title=Modding:Pants&oldid=190705), [NPC portrait/sprite data](https://stardewvalleywiki.com/Modding:NPC_data).

### Fishing and social guidance (0.3.0)

All 72 fish have individually cited route profiles in `src/domain/fishing.ts`. Each profile retains source IDs, verification date and version applicability. Research included the individual fish pages, [Fish](https://stardewvalleywiki.com/Fish), [Crab Pot](https://stardewvalleywiki.com/Crab_Pot), [Magic Bait](https://stardewvalleywiki.com/Magic_Bait) and [Training Rod, revision 194241](https://stardewvalleywiki.com/mediawiki/index.php?title=Training_Rod&oldid=194241). Location-season combinations are kept separate; festival dates, special access and Fishing levels are not bypassed by Magic Bait. The planner cannot confirm current weather, time, equipment or location access.

The 34 villager birthdays/home notes in `src/domain/social.ts` link to individual Wiki pages, retained under `wiki-npc-*` in `data/sources.json`. [Friendship](https://stardewvalleywiki.com/Friendship) supports heart thresholds and relationship caps. Actual friendship points, status, spouse and available daily interaction counters come from the selected disk save. The displayed social cap is separate from the Perfection friendship target; unknown daily fields are never filled with zero. Full daily schedules are linked, not reconstructed.

Static base frames are previews: dyed/prismatic layers, animation, procedural variations and mod-provided virtual textures are not simulated. Source-sheet variants are included where present; there is no claim of exhaustive live in-game appearance reconstruction.

The Wiki Collections page (https://stardewvalleywiki.com/Collections) resolved a reference discrepancy: Clam is in the Fish collection in 1.6, not shipping. The 1.6 shipping catalog therefore has 154 entries.

Every entry has a stable ID, game-version applicability, verification date, confidence and source references. `catalog` means identity/collection membership checked against the MIT reference, **not** that a detailed guide was verified. Detailed guides have their own references. Missing guidance is displayed as unavailable and links to a verified category page rather than an invented item URL. Unknown weather, random stock, unknown storage and unsupported conditions stay unknown.

### Expanded game data (0.4.0)

The native reader supplies 20 installed dictionaries: recipes/ingredients, crops, forage, shops, TV episodes, letters, special orders, buildings, machines, monsters, characters and schedules. [Recipe data](https://stardewvalleywiki.com/Modding:Recipe_data), [machine rules](https://stardewvalleywiki.com/Modding:Machines), [monster data](https://stardewvalleywiki.com/Modding:Monster_data) and [schedules](https://stardewvalleywiki.com/Modding:Schedule_data) retain manifest references. `data/recipe-unlocks.json` records additional verified event/mastery facts. Installed schedules are parsed as conditional references; the historical 0.3 description above applies to that release.

[Museum](https://stardewvalleywiki.com/Museum), [bundles](https://stardewvalleywiki.com/Bundles), [quests](https://stardewvalleywiki.com/Quests) and [walnuts](https://stardewvalleywiki.com/Golden_Walnut) support optional completion guidance. Actual definitions, donation flags, journals and markers come from the save. The 69 walnut evidence groups totaling 130 are adapted from the MIT Checkup reference, retaining its notice.

Location maps use an original bounded Rust tBIN10 decoder based on the [MIT TBIN format reference](https://github.com/mapeditor/tiled/tree/master/src/plugins/tbin/tbin), retaining `research/TBIN_LICENSE`. Static paths omit live objects, door opening and generated floor changes. Turkish game strings and proprietary map/sprite pixels stay local and are not redistributed. Public serialization metadata is reflected only by the opt-in development script; no game methods execute.

## Correctness and guidance expansion (0.5.0)

Research on 2026-10-16 used [Achievements, revision 189827](https://stardewvalleywiki.com/mediawiki/index.php?title=Achievements&oldid=189827), [Books](https://stardewvalleywiki.com/Books), [Giant Stump](https://stardewvalleywiki.com/Giant_Stump), [Marriage](https://stardewvalleywiki.com/Marriage), [Friendship](https://stardewvalleywiki.com/Friendship) and [Stardrop Tea](https://stardewvalleywiki.com/Stardrop_Tea). New guidance is original concise wording; only factual item IDs and counters from the local game are bundled. `data/achievement-records.json` maps 39 positive in-game records; absence never proves a Steam account is locked. The museum list contains 95 vanilla donation identities. Crop and book eligibility are versioned, and action guides remain useful when the save cannot prove an action.

[Monsters, revision 191503](https://stardewvalleywiki.com/mediawiki/index.php?title=Monsters&oldid=191503) supports region/floor bands. They do not guarantee a spawn on an individual generated floor. Dangerous scaling and special loot are not invented from base data. [Map properties](https://stardewvalleywiki.com/Modding:Maps) support explicit warp connections. Known saved blocking objects, mature trees, clumps and explicit building footprints are overlaid without changing original map data; unknown objects and story changes remain limitations.

[Event conditions, revision 195305](https://stardewvalleywiki.com/mediawiki/index.php?title=Modding:Event_data&oldid=195305) and [game state queries](https://stardewvalleywiki.com/Modding:Game_state_queries) informed a bounded set of 1.6 condition explanations. Newer-version query features are not assumed supported. Heart-event headers are read locally; event scripts/dialogue are neither executed nor bundled. Unknown clauses, live weather/time, festival/island schedule overrides and mail delivery timing remain checks in game. The native metadata reader now supplies 22 dictionaries, including achievements and festival dates.

Positive source links retain the research manifest. In 0.5, unverified individual pages used Wiki search. Version 0.7 replaces that search with a canonical English page link and an explicit unverified-page notice. Proprietary assets and private QA data remain local and excluded from packages.

## Permitted import workflow

The 0.9 research pass retained [Quest data](https://stardewvalleywiki.com/Modding:Quest_data), [crop quality](https://stardewvalleywiki.com/Crops#Crop_Quality), [Skills](https://stardewvalleywiki.com/Skills#Farming), [Artisan Goods](https://stardewvalleywiki.com/Artisan_Goods), [Wine](https://stardewvalleywiki.com/Wine), [Smoked Fish](https://stardewvalleywiki.com/Smoked_Fish), [Dried Fruit](https://stardewvalleywiki.com/Dried_Fruit), [Mayonnaise](https://stardewvalleywiki.com/Mayonnaise), [Cooking](https://stardewvalleywiki.com/Cooking#Qi_Seasoning) and [profit margins](https://stardewvalleywiki.com/Multiplayer#Profit_Margins), checked 2026-10-18. Object/equipment values are read from the installed game; authored quality/profession/variant rules retain these references. Missing price evidence remains unknown. Isolated serializer and recipe-event probes used the installed vanilla 1.6.15 assembly and synthetic XML only. Private decompilation notes remain ignored and are not distributed. No game save, original asset or game DLL is modified.

The 0.8 saved-progress behavior was checked against [Saves](https://stardewvalleywiki.com/Saves) on 2026-10-18: the normal PC save is written at the end of the day. Companion reads that disk state on watcher notifications or its next launch. It does not receive unsaved game actions. [Animals](https://stardewvalleywiki.com/Animals), including its Pets and Horse sections, was checked the same day for the gallery's source links. Both references are retained in `data/sources.json`. Animal cropping only changes preview rectangles over the installed texture; original assets stay read-only. Local extraction now supplies 6,283 Turkish display strings, including known display fields in hats, boots and furniture. Neither those proprietary strings nor game pixels are redistributed in packages.

Use `npm run knowledge:validate` to validate the bundle. `scripts/import-knowledge.mjs` imports a deliberately prepared local JSON file with citations and version metadata; it does not fetch restricted pages. Contributors can prepare a small dataset from information they are permitted to access, retain revisions where available, apply the content license, and submit it for review. See `docs/KNOWLEDGE_IMPORT.md`. A future downloader must check robots and API policy before every batch, use an identifying User-Agent, a single request queue, >=2 second spacing, a disk cache and bounded exponential retries. It must stop on 401/403/429 and never circumvent restrictions.


## Design workspace reference (0.11)

[Stardew Planner](https://stardewplanner.com/) was inspected as an interaction reference for click placement, continuous paint, dragging and tool access. No source code or site art was copied. Home templates and furniture sprite/collision dimensions come from the user's installed map and Data/Furniture assets. Saved interior instance names are resolved through Building.nonInstancedIndoorsName or legacy nested uniqueName and Data/Buildings.IndoorMap. Renovations and spouse decorations are not claimed reconstructed. Local QA verified all 48 saved container maps from four read-only profiles; no proprietary assets or private snapshots enter the package.
